# Upload to GitHub

1. Extract `amr-analysis-and-visualization.zip` and open the `amr-analysis-and-visualization/` folder.
2. Create an empty GitHub repository named `amr-analysis-and-visualization` under your account.
3. Upload the contents of the extracted folder, including the README, .gitignore, source package, examples, tests and documentation. Keep their relative paths.
4. Commit to the default branch and check the example link from the README.
